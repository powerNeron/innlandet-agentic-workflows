# Experimental protocol and change boundary

Experiments were selected after inspecting the actually available assignment text, existing harnesses, synthetic fixtures, prompt log, decision notes and previous evidence package. Researcher-selected additions comprise causal recovery, concurrent negative HTTP controls, actual token measurements, budget boundaries and the distinction between state reset and computation cancellation. They are not presented as verbatim teaching requirements.

For each F case, hypothesis, baseline, perturbation, expectation, observation, call count, recovery and limitations are preserved in ../logger/fault-injection.json and 06. Application functionality was not changed. Existing correction was tested; new global controls require separate authorization. Safety probes used synthetic data only. No external party received access; no tunnel, commit or push was performed.
