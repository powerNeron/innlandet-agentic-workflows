# Codex-arbeid, beslutninger og møter

Det finnes 8 kandidatnotater i docs/meetings. Ingen av de 8 kan i dette revisjonssporet bekreftes som et faktisk møte med deltakerbekreftelse. Dette betyr ikke at møter ikke fant sted. Antall dokumentfiler er ikke antall genuine møter. Notatene inneholder implementasjonsvalg, testsummer, eierskapsgrenser og revisjoner; studentene må selv bekrefte faktisk møteproveniens uten å publisere personopplysninger.

Tidligere Codex-endringer som inngår i commit-grunnlaget: synlig eksport og manuelt kontrollpanel fjernet, tekster forenklet og Om tjenesten lagt til, med regresjonstester. Denne oppgaven endrer bare resultatpakken. docs/prompt-log.md har saniterte sammendrag; representative faktiske dialogutdrag finnes i 17_prompt_excerpts.md. Bekreftede teammøter og individualisert arbeidsfordeling kan ikke konstrueres av assistenten.
